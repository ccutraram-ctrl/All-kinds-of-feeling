THE POCKET ASSEMBLY — ALL KINDS OF FEELING
Public official album site with download, all under GitHub. NO GOOGLE DRIVE.

TWO FILES ARE PROVIDED:
 A. The Pocket Assembly - Website (No Google Drive).zip (this small website, ~6MB)
 B. All-Kinds-of-Feeling-The-Pocket-Assembly.zip (the album, ~200MB)

PUBLISH ON GITHUB
1. Sign in/sign up at https://github.com and create a PUBLIC repository called
   'the-pocket-assembly' (or another name of your choice).
2. Extract the WEBSITE zip. In the new repo, use Add file > Upload files
   to upload the WEBSITE CONTENTS (index.html, styles.css, app.js, config.js,
   assets/, previews/, etc.) to the root of the repository. Commit.
   Do NOT add the 200MB album ZIP to repository files.
3. Go to Settings > Pages > Build and deployment > Deploy from a branch.
   Select branch 'main' and folder '/ (root)', then Save.
   GitHub gives you a public URL (username.github.io/the-pocket-assembly/).
4. In that same repo, open Releases > Draft a new release.
   Set tag to 'v1.0.0' and attach the big album ZIP with exact name:
   All-Kinds-of-Feeling-The-Pocket-Assembly.zip
   Publish the release.
5. That's all! The public website will show artwork, 12 song previews,
   and a DOWNLOAD ALL 12 TRACKS button. It links to the album release
   in the SAME GitHub project. No Google Drive, no config editing.

IMPORTANT:
- The website isn't publicly hosted just because the files are built.
  You need a hosting account (GitHub Free supports public Pages sites).
- The download button works once the release asset is published.
- The website is deliberately small for easy upload.
- The album is offered as one ZIP; the 12 previews are part of the site.
- Never upload the album ZIP to GitHub repository Code files: it is too
  large for normal GitHub repository file limits. Use Releases instead.
- Keep your original WAV files backed up separately.
